# Cronograma

Ordem sugerida dos encontros. Preencha as datas no calendário acadêmico de cada semestre. Identifique cada encontro pelo **assunto** (nome da pasta em `aulas/`), não por um número de aula — a ordem pode mudar de um semestre para outro.

Feriados e recessos do campus **não têm material de aula** — pule o encontro e continue na pasta seguinte.

As interfaces e os integradores de POO podem ocupar uma janela sem encontro presencial (feriados, recesso). A aula de integradores da disciplina é revisão em casa na semana da aula de boas práticas.

## Visão por unidade

```
Unidade 1
  Revisão → Classes/objetos → Atributos/construtores/métodos
  → Encapsulamento/pacotes → Relacionamentos → Diagrama UML

Unidade 2
  Herança → Polimorfismo → Interfaces/abstratas
  → Classes internas → Recursão → Integradores POO → Prova

Unidade 3
  Debug → Wrappers → Boas práticas → Integradores → Prova
```
