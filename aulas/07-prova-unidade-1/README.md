## Instruções ao docente

- Instrumento em `prova.md` (versão para impressão). Pontuação total 10,0.
- Gabarito em `gabarito.md`.
- Sem consulta a caderno. Java no papel: aceite pequenos erros de ponto-e-vírgula se a lógica estiver correta; cobrem conceitos.

- Código de apoio mínimo (se quiser laboratório digital em vez de papel) está em `src/` — não é necessário para a prova escrita.
